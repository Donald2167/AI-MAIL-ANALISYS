과제 개요

구분현황 및 문제점
메일 과부하1인당 하루 평균 30~50통 수신, 확인/분류에 상당 시간 소요

정보 검색 한계과거 메일 확인 시 일일이 검색해야 하며 맥락 파악에 시간 소요

워크플로우

단계처리 내용
① EML 스캔mail_data/ 폴더의 .eml 파일 목록 수집
② 파싱제목·발신자·날짜·본문·첨부파일 추출, 전달(FW) 메일 실 발신자 추출
③ 중복 체크eml_ID 비교 → 신규만 처리 (--force 시 전체 재파싱)
④ 자동 분류키워드 기반 7개 카테고리 분류 (LLM 분류 선택 가능)
⑤ 우선순위 분석긴급 여부 판별 / 마감일 추출 / 우선순위 점수 / 액션 아이템
⑥ 저장data/emails.json에 병합 저장
⑦ 대시보드Streamlit 대시보드 → http://localhost:8501
4

주요 기능

📂 EML 일괄 파싱

mail_data/ 폴더의 .eml 파일 자동 파싱, 중복 건너뜀 (--force 재파싱 지원)

🏷️ 자동 분류

회신필요 / 결재요청 / 회의참석요청 / 단순공지 / 보고/공유 / 업무요청 / 기타 (7개 카테고리)

👤 발신자 추출

전달(FW) 메일의 실 발신자를 본문 HTML에서 정확히 추출 (ForwardedEmailInfo)

🚨 긴급·마감 분석

긴급 여부 자동 판별, 마감일 추출, 우선순위 점수 산정, 액션 아이템 추출

💬 회신 필요 메일 관리 NEW

스크롤 가능한 회신필요 메일 목록 + LLM 메일 요약 + 간결·정중한 LLM 회신 초안 자동 작성

🤖 AI 질의 NEW

설정 탭에 저장된 LLM을 재사용, 점수 기반 관련 메일 우선 검색 후 자연어 답변 생성

📊 Streamlit 대시보드

통계·우선순위·발신자별 분류 웹 UI (http://localhost:8501)

📄 HTML 보고서

Chart.js 기반 시각화 포함 HTML 보고서 자동 생성 및 다운로드

🔍 RAG 질의

TF 임베딩(SimpleVectorStore) 코사인 유사도 검색 + LLM 자연어 질의

📬 주간 보고서 자동 발송

Exchange Online SMTP 기반 HTML 메일 자동 발송, 첨부파일 지원

LLM 연동

🤖

OpenAI  OpenAIClient

모델: gpt-4o-mini · 환경변수: OPENAI_API_KEY

✨

Google Gemini  GeminiClient

모델: gemini-2.5-flash · 환경변수: GEMINI_API_KEY

🦙

Ollama (로컬)  OllamaClient

모델: llama3 · 주소: http://localhost:11434

🧪

Mock (테스트)  MockLLMClient

API 키 없이 동작 확인 가능

⚙️ LLM 설정 항목 (설정 탭)

항목설명
LLM 제공자openai / gemini / ollama 중 선택
API 키OpenAI 또는 Gemini API 키 (Ollama는 불필요)
모델명gpt-4o-mini / gemini-2.5-flash / llama3 등
Max TokensLLM 응답 최대 토큰 수 (기본값: 1000, 범위: 100~8000) — 모든 LLM 호출에 공통 적용
한 번 저장하면 전체 적용 — 설정 탭에서 저장한 LLM 설정이 메일 요약, 회신 작성, AI 질의 모든 기능에 자동으로 적용됩니다. (data/llm_config.json)

💡 AI 질의 사용법

  1. ⚙️ 설정 탭에서 LLM 제공자 및 API 키 저장
  2. 🔍 검색/질의 메뉴 → 🤖 AI 질의 탭 선택
  3. 자연어로 질문 입력 후 질문하기 클릭
